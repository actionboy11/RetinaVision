# Agent 评测与可观测性闭环设计

## 目标

在现有医生 Agent、患者 Agent、Skill 管理和 Prompt/RAG 评测基础上，建设统一的 Agent 评测中心。评测使用固定匿名数据，不读取真实临床数据，不污染正式 Agent 会话；管理员手动触发真实模型评测，自动化测试默认不调用外部模型。

## 核心设计

- 固定匿名评测集覆盖医生、患者、多轮上下文、RAG 连接和安全攻击五类场景，共约 180 条。
- 真实模型负责 Skill 路由和参数提取；Native Skill 使用匿名 Fixture 查询适配器执行，知识 Skill 使用固定检索片段验证受众与引用。
- 评测运行冻结数据集、模型、Skill 和 Prompt 版本，并保存逐样例结果、失败类型与耗时。
- 评测不写入正式会话或 Skill 执行日志；LLM 调用日志以 `EVALUATION` 来源和运行 ID 标记。
- 同时只运行一个真实模型评测，逐条执行并允许在当前请求结束后取消。
- 程序确定性评分决定自动通过，管理员人工抽查后批准；LLM Judge 不参与启用判断。

## 启用门槛

- 路由准确率不低于 90%。
- 参数准确率不低于 95%。
- 查询结果准确率不低于 95%。
- 结构、安全和引用校验通过率必须为 100%。
- 有效样例 P95 响应时间不超过 5 秒。
- 候选 Skill 或关键 Router Prompt 必须存在绑定当前模型和匹配角色数据集的 `PASSED + APPROVED` 运行。
- 已启用的历史版本不追溯停用。

## 管理体验

管理员可查看评测集、启动评测、轮询进度、查看指标和失败样例、取消运行并人工批准或拒绝。医生、患者和研究员不能访问页面或 API。第一版不在线编辑安全样例、不定时调用模型、不自动启用版本，也不接入 MCP/HIS/PACS。
